# Collector Widget — Android

Минимальный Android App Widget для размещения фотографии на домашнем экране **без белой рамки и белой подложки**.

## Как открыть проект
1. Распакуйте архив.
2. Откройте папку `NothingCollectorWidget` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Подключите Android-телефон и нажмите Run.
5. На рабочем столе откройте список виджетов и добавьте **Collector Widget**.
6. Нажмите на виджет, чтобы выбрать фотографию. После выбора она появится без белой обводки.

## Важно
- Исходник рассчитан на Android 6.0+ и Android Studio с Android Gradle Plugin 8.7.3.
- Это исходный проект, а не готовый APK: APK собирается в Android Studio через Build → Build APK(s).
- Виджет использует `centerCrop`: фотография заполняет всю область, поэтому края могут обрезаться при неподходящем соотношении сторон.
- Белая рамка не рисуется приложением; если лаунчер сам добавляет системное выделение при перетаскивании/нажатии, это временный эффект интерфейса лаунчера.

## Сборка APK через GitHub Actions (без Android Studio на телефоне)

1. Создайте новый репозиторий на https://github.com/new.
2. Загрузите в него **содержимое этой папки проекта** (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** репозитория.
4. Если GitHub попросит разрешить запуск Actions, разрешите запуск workflows.
5. Дождитесь завершения задания **Build Android APK**.
6. Откройте завершённый запуск и скачайте артефакт `NothingCollectorWidget-debug`.
7. Распакуйте скачанный ZIP — внутри будет `app-debug.apk`.

Сборка запускается автоматически после загрузки файлов в ветку `main`; её также можно запустить вручную через **Actions → Build Android APK → Run workflow**.
